# Viva Questions and Answers

## 1. What is a Job Portal?
A Job Portal is a website where people can search for jobs, apply to companies, and manage their job applications.

## 2. Why did you choose this project?
I chose this project because it helps me learn web development, database design, and real-world application flow in a simple and practical way.

## 3. What is HTML?
HTML is the structure of a webpage. It is used to create headings, forms, buttons, tables, and content.

## 4. What is CSS?
CSS is used to design the webpage. It controls color, spacing, layout, buttons, cards, and responsiveness.

## 5. What is JavaScript?
JavaScript is used to make web pages interactive. It handles form validation, search, filters, and button actions.

## 6. What is SQL?
SQL is a language used to work with databases. It is used to create tables, insert records, update data, and fetch information.

## 7. What is SQLite?
SQLite is a lightweight database system that stores data in a single file. It is simple and useful for small projects.

## 8. What is a primary key?
A primary key is a unique value used to identify each row in a table.

## 9. What is a foreign key?
A foreign key is a column that refers to the primary key of another table. It helps connect related data.

## 10. What is CRUD?
CRUD means Create, Read, Update, and Delete. These are the four main operations of database management.

## 11. What is a database?
A database is a structured collection of data stored so it can be accessed, updated, and managed easily.

## 12. What is normalization?
Normalization is the process of organizing data to reduce duplication and keep the database efficient.

## 13. What is a JOIN?
A JOIN is used to combine rows from two or more tables based on a related column.

## 14. What is validation?
Validation means checking whether the user input is correct, complete, and safe before storing or processing it.

## 15. What are the three user roles?
The three roles are Job Seeker, Employer, and Admin.

## 16. How does a job seeker apply?
A job seeker registers, logs in, searches jobs, opens a job, and clicks the Apply button. The application is then tracked in the dashboard.

## 17. How does an employer post a job?
An employer logs in, goes to the post job page, fills the form, and submits the details. The job appears in the job list.

## 18. What does the admin do?
The admin can view users, jobs, applications, and manage the overall system.

## 19. What are the limitations?
This project is a simple demo and does not include real payment systems, live email sending, or a full server-side database connection.

## 20. What is the future scope?
In future, the project can include real SQLite backend integration, user authentication, resume upload, online interviews, and employer dashboard improvements.
